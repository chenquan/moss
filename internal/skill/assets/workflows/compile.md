# Compile

Run `compile.start`, then `compile.next`/`compile.submit` in extract → classify → write order, sending each envelope through stdin/stdout. Use `source_ids` for a related multi-source job; the legacy `source_id` remains supported. Write only the exact managed stage `result_file` returned by Moss. Use `compile.preview` and the confirmed `compile.apply` gateway before claiming that a Wiki article changed. Reserve generic `plan.apply` for forget and rollback safety plans.
